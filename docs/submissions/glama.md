# Glama

- Site: https://glama.ai/mcp/servers , "Add server" with the public repository URL; Glama indexes from the repo and checks the build.
- Claim the listing by adding your Glama user to `glama.json` -> `maintainers` (currently empty on purpose; fill with the owner's Glama username at submission time).
- Glama may build the repository from the Dockerfile to introspect it; both transports work (`npm start` for HTTP, `node dist/index.js --stdio`). Unverified: Glama's exact build steps change, check its current docs before submitting.
- Description: Read-only TaskSiddhi product facts for AI assistants: capabilities and honest limits, free-vs-custom pricing, sourced competitor comparisons, free SOP and planner templates.
