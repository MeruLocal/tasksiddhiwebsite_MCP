# Audit summary, 2026-10-22

Server audited: the public website MCP for TaskSiddhi (this repository). Measured against the repository state at the start of this change and the live hosts.

## Starting state (measured)

- The repository was empty: no commits, no branches, no pull requests. There was no server to audit.
- `mcp.tasksiddhi.com` did not resolve; `https://tasksiddhi.com/mcp`, `/.well-known/mcp.json` and `/.well-known/mcp/server-card.json` returned 404; the site's `llms.txt` does not mention an MCP.

## What this change adds

A stateless Streamable HTTP server (plus stdio) with 8 read-only, annotated tools, 4 resources, 3 prompts, a server card, `llms.txt`, `robots.txt`, `/health`, `/version`, a conformance probe, 19 tests, and directory submission packets (`docs/submissions/`, prepared, not submitted).

## Content rules enforced by tests

- Pricing follows the site's decision: Free Forever plus a quoted Custom plan; no per-user price, currency, trial or limit figure appears on TaskSiddhi's side.
- No Gantt, guest access, native iOS, offline mode, PDF export or direct competitor importer is ever claimed; a capability the site does not state is answered `not_stated`.
- Competitor facts are mirrored with their checked date and a "may have changed" caveat.
- No sibling brand or parent company is named anywhere in the repository or served data.

## Not verified

Live behaviour (nothing is deployed), Docker build, directory acceptance criteria, official conformance harness and Inspector (not downloaded), competitor prices (mirrored, not re-checked).
